# How to Add My Next Case Study

When I complete a new project, I will add it to the Projects / Case Studies section of my portfolio.

I will use three parts:

1. Problem — Explain what problem the project solves.
2. What I did & decided — Explain what I built, the technologies I used, and important decisions I made.
3. What came of it — Explain the result and what I learned.

I will also add project screenshots and the GitHub link. I will use my existing Claude Project to keep the same portfolio style and voice.
